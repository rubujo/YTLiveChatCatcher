# WinForms 發佈前 smoke test

GitHub Actions 會自動執行 Release 建置、純邏輯測試與程序啟動 smoke test；下列需要互動式 Windows 桌面的項目必須在發佈前逐項實測，不得以單元測試推論為通過。

| 項目 | 操作 | 通過條件 |
|---|---|---|
| 啟動 | 在乾淨的使用者 profile 啟動程式 | 5 秒內出現主視窗，沒有啟動期例外 |
| 開始／停止 | 使用目前有效的直播 ID 開始，收到至少一批後停止，再開始一次 | UI 不凍結、按鈕狀態復原、第二次能正常擷取 |
| XLSX 往返 | 匯出完整聊天室，再把同一檔案匯入 | 列數、主要欄位、金額與 Unicode 內容一致 |
| 搜尋 | 使用作者、訊息文字及不存在關鍵字搜尋 | 結果正確，清除後列數歸零 |
| 大量資料 | 載入至少 50,000 筆資料並搜尋、捲動、匯出 | VirtualMode 可操作，介面沒有長時間無回應 |
| Cookie 邊界 | 貼上含 CRLF／LF、前後空白與空值的 Cookie；測試登入、登出 | 不把換行寫入標頭；登出後 `cookie.dat` 與 WebView2 profile Cookie 均清除 |
| 復原／續傳 | 擷取中強制結束程序，重開後載入並續傳 | 已落地批次恢復、重疊訊息不重複、manifest 保守顯示完整性 |
| 資料工具 | 套用各種篩選，匯出 JSONL／CSV，產生分析與診斷包 | 筆數一致；CSV 正確逸出；診斷包不含 Cookie／Token／continuation |

若無有效直播、WebView2 或互動式桌面，對應項目應記為「未測試」，不能記為通過。
