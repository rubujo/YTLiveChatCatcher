# YouTube 聊天室捕手

## 一、簡述

模擬 YouTube 直播聊天室網頁版的行為，以取得直播中或一般影片的聊天室內容，並提供簡易的收益分析、報表匯出等等功能。

## 二、功能

1. 提供輸入 YouTube 頻道網址，以自動取得該 YouTube 頻道最新影片的影片 ID 的功能。
2. 提供輸入 YouTube 影片網址或影片 ID，以自動反查該影片所屬頻道 ID 的功能（僅在頻道 ID 欄位為空白時才會自動帶入，不會覆蓋您已手動輸入的內容）。
3. 提供簡易的聊天室內容搜尋功能。
4. 整合 Microsoft Windows 的 Text-to-Speech 服務，用以點選聊天內容，讓 Text-to-Speech 服務說出已點選聊天內容的功能。
5. 提供即時的簡易收益分析功能（依貨幣符號分別加總，不做匯率換算，主要面向新臺幣超級留言／貼圖）。
6. 提供將聊天室內容匯出成 Microsoft Excel 檔案格式的功能。
   - 內容如下列：
     - 即時聊天的資料。
     - 時間熱點。
     - 自定義表情符號。
     - 會員徽章。
     - 超級貼圖。
   - 勾選「匯出頭像」時，頭像是以 Excel 365 的 `IMAGE()` 公式匯出（不會內嵌成檔案內的圖片，維持檔案輕量），需要 Microsoft 365 版本的 Excel、且開啟時本機網路暢通，才能讓 Excel 自己下載並顯示頭像。若頭像儲存格顯示 `#BLOCKED!`、Excel 提示「已停用連結的資料類型」，這是 Excel 的信任中心「連線的體驗／已連結的資料類型」安全政策擋下 `IMAGE()` 的網路存取，屬於 Excel 本身的全域設定，不是檔案本身的問題；請至「檔案 > 選項 > 信任中心 > 信任中心設定 > 連線的體驗」啟用相關選項後再重新開啟檔案。
7. 提供將頻道的社群貼文（含投票、分享的影片等）完整匯出成 Microsoft Excel 檔案格式的功能。
8. 提供取得會員限定影片的聊天室內容的功能。
   - 點選「登入 YouTube 帳號...」開啟專屬的登入視窗（`Microsoft.Web.WebView2`，使用獨立的 user data folder，不會讀取或依賴您日常瀏覽器的資料），登入後即可取得該視窗的 Cookie；若無法使用 WebView2，也可以在同一個視窗手動貼上自行從瀏覽器複製的 Cookie 字串。
   - 勾選「記住我」才會將 Cookie 以 Windows DPAPI 加密儲存在本機，否則僅存在記憶體、關閉程式即遺失。
   - `※需要自行購買該頻道的會員。`
9. 擷取期間會把已收到的批次以 Windows DPAPI（CurrentUser）加密後，附加寫入 `%LocalAppData%\YTLiveChatCatcher\recovery.jsonl`；若程式意外結束或尚未匯出，下次啟動時可選擇載入。成功匯出或手動清除聊天室後會刪除這份復原記錄。

## 三、注意事項

1. 請慎用「登入 YouTube 帳號」與「記住我」功能，妥善保管您本機儲存的登入資料。
2. 請勿過於頻繁的使用本應用程式。
3. 同一個 Windows 桌面工作階段只允許執行一個應用程式實例，避免多個程序同時寫入復原記錄、設定與快取資料。
